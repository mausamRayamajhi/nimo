# Coingecko

This project showcases a robust and scalable architecture using **BLoC** for state management, **dio** for network requests, and a modular design with multiple screens and reusable widgets.

---

## 🚀 Key Features

- **Navigation**: Seamless and intuitive navigation using the powerful [auto_route](https://pub.dev/packages/auto_route) package for declarative routing and code generation.
- **Dependency Injection**: Efficient dependency management using the [get_it](https://pub.dev/packages/get_it) service locator.
- **BLoC (Business Logic Component)**: A predictable and testable state management solution that separates the UI from the business logic.
- **Multiple Screens & Widgets**: A modular design with dedicated screens and reusable, encapsulated widgets.
- **Network API Calls**: Efficient and reliable data fetching from external APIs.
- **Model Class Conversion**: Automated conversion of JSON responses into strongly-typed Dart model classes for easy data handling.
- **Test Cases**: Comprehensive unit tests for BLoC and model classes to ensure stability and correctness.

---

## 🛠️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### ✅ Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (^3.35.1) installed.
- A suitable IDE (VS Code or Android Studio) with the Flutter plugin.

### 📥 Installation

Clone the repository:

```bash
git clone git@github.com:mausamRayamajhi/nimo.git
````
### 📥 Installation
Run the script to build the project:

```bash
sh scripts/build_project.sh
```
